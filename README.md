# 마지막 접속 · Last Access

> “내가 연락이 안 되면, 내 컴퓨터부터 확인해 줘.”

약속 장소에 나타나지 않은 친구가 예약 메시지를 남겼습니다. 친구의 컴퓨터에 남은 파일과 대화, 일정을 살펴보고 무슨 일이 있었는지 밝혀 주세요.

**마지막 접속**은 컴퓨터 브라우저에서 즐기는 한국어 1인 추리 게임입니다. 서로 맞지 않는 기록을 찾아 단서를 모으고, 잠긴 자료를 열어 사건의 진상을 추리합니다. 화면 속 컴퓨터와 자료는 모두 게임의 일부이며, 사용자의 실제 파일이나 계정에 접근하지 않습니다.

## 게임 시작하기

현재는 게임 폴더를 내려받아 내 컴퓨터에서 실행하는 방식입니다. 아래 안내는 Windows 기준입니다.

### 처음 실행할 때

1. Node.js 22.12 이상이 설치된 컴퓨터를 준비합니다. 개발 시 확인한 환경은 Node.js 24.18.1과 npm 11.16.0입니다. npm은 Node.js와 함께 설치됩니다.
2. 게임 폴더(`package.json` 파일이 있는 폴더)를 열고, 폴더의 빈 곳을 마우스 오른쪽 버튼으로 눌러 **터미널에서 열기**를 선택합니다. Windows 버전에 따라 메뉴 이름은 다를 수 있습니다.
3. 터미널에 아래 명령을 입력하고 설치가 끝날 때까지 기다립니다. 이 단계에는 인터넷 연결이 필요합니다.

   ```powershell
   npm.cmd ci
   ```

4. 설치가 끝나면 다음 명령을 입력합니다.

   ```powershell
   npm.cmd run dev
   ```

5. 터미널에 표시된 주소를 브라우저에서 엽니다. 기본 주소는 `http://127.0.0.1:5173`입니다.
6. 시작 화면에서 **새 게임**을 선택합니다. 이전에 플레이했다면 **이어하기**로 돌아올 수 있습니다.

플레이하는 동안 터미널 창을 열어 두세요. 실행을 마치려면 터미널에서 `Ctrl+C`를 누릅니다. 게임 파일을 더블클릭해서 여는 방식은 지원하지 않습니다.

### 다음에 다시 실행할 때

게임 폴더에서 터미널을 열고 `npm.cmd run dev`를 실행한 뒤, 같은 브라우저와 같은 주소로 접속하세요. 매번 다시 설치할 필요는 없습니다.

## 어떻게 플레이하나요?

1. **기록을 살펴보세요.** 바탕화면의 **파일 탐색기**, **메신저**, **일정**을 열어 친구가 남긴 자료를 읽습니다. 여러 문서를 나란히 열어 비교할 수 있습니다.
2. **증거를 모으세요.** 자료에서 **증거 기록**을 누르면 **조사 노트**에 보관됩니다. 자료를 읽기만 하면 증거로 등록되지 않습니다.
3. **생각을 적어 두세요.** 조사 노트의 메모에 의심스러운 점이나 기록 사이의 관계를 적어 보세요. **원본 다시 열기**를 누르면 증거가 나온 자료로 돌아갑니다.
4. **잠긴 자료를 열어 보세요.** 다른 기록에서 찾은 단서를 바탕으로 비밀번호를 추리합니다.
5. **답과 근거를 제출하세요.** **진상 제출**에서 질문마다 답과 필요한 개수의 증거를 선택합니다. 틀렸다면 자료를 다시 조사하고 수정해 제출할 수 있습니다.

막히면 **힌트**를 열어 보세요. 대상마다 세 단계가 있으며, 뒤 단계일수록 정답에 가까워집니다. 공개한 힌트는 되돌릴 수 없으니 확인창을 읽고 선택하세요.

정답을 확인하고 싶을 때만 [스포일러가 포함된 공략](docs/walkthrough.spoilers.md)을 여세요.

## 화면 조작

- **앱 열기:** 바탕화면의 앱을 클릭합니다. 키보드로는 `Tab`으로 이동하고 `Enter`로 선택합니다.
- **창 이동:** 창 위쪽의 제목 표시줄을 마우스로 끕니다.
- **창 크기와 표시:** 창 위쪽의 최소화·최대화·복원·닫기 버튼을 사용합니다. 최소화한 창은 화면 아래 작업표시줄에서 다시 열 수 있습니다.
- **긴 자료 읽기:** 문서 안에서 스크롤합니다.

컴퓨터의 넓은 화면에서 플레이해 주세요. 화면 검사는 Chromium 브라우저의 1280×720과 1920×1080 크기에서 진행했습니다.

## 저장하고 이어하기

진행 상황은 플레이 중인 브라우저에 자동으로 저장됩니다. 증거 수집·잠금 해제·힌트 공개·답안 변경은 즉시 저장하며, 메모는 입력을 멈춘 뒤 약 0.3초 후 또는 메모 입력칸을 벗어날 때 저장합니다. 메모는 최대 20,000자까지 적을 수 있습니다.

다시 접속하거나 새로고침한 뒤 시작 화면에서 **이어하기**를 선택하세요. 조사 내용과 메모는 복원되지만, 창의 위치와 크기는 기본 상태로 돌아갑니다.

저장할 때는 다음을 기억해 주세요.

- **저장 공간은 한 개입니다.** 기존 진행이 있을 때 **새 게임**을 선택하고 초기화를 확인하면, 이전 진행과 메모가 삭제됩니다.
- **같은 브라우저와 주소를 사용하세요.** 브라우저·프로필·접속 주소·포트 번호가 달라지면 기존 저장이 나타나지 않습니다. 브라우저의 사이트 데이터를 지우면 저장도 삭제됩니다.
- **한 탭에서 플레이하세요.** 여러 탭의 진행을 합치는 기능은 없습니다. 다른 탭에서 저장이 바뀌었다는 안내가 나오면, 저장하지 못한 메모를 따로 복사한 뒤 **저장 다시 불러오기**를 선택하세요.
- **저장 오류를 확인하세요.** 저장에 실패해도 현재 화면에서 계속할 수 있지만, 창을 닫거나 새로고침하면 저장하지 못한 진행이 사라질 수 있습니다. 중요한 메모를 먼저 복사해 두세요.

## 실행이나 저장이 잘되지 않을 때

| 상황 | 확인할 내용 |
| --- | --- |
| `npm.cmd`를 찾을 수 없다고 나옵니다. | Node.js 설치 여부를 확인하고 터미널을 새로 연 뒤 다시 실행하세요. |
| 게임 화면이 열리지 않습니다. | 터미널에서 실행이 계속되고 있는지 확인하세요. 기본 주소 대신 다른 주소가 표시되면 그 주소를 여세요. |
| 필요한 파일이나 패키지가 없다는 오류가 나옵니다. | 실행 중인 게임 터미널에서 `Ctrl+C`를 누른 뒤, 게임 폴더에서 `npm.cmd ci`를 다시 실행하세요. 설치가 끝나면 `npm.cmd run dev`로 시작하세요. 같은 오류가 계속되면 오류 내용을 실행을 도와준 사람에게 전달하세요. |
| **이어하기**가 보이지 않습니다. | 이전에 사용한 브라우저·프로필·주소·포트 번호가 같은지 확인하세요. |
| 저장 데이터를 불러올 수 없다고 나옵니다. | 기존 저장은 초기화를 확인하기 전까지 보존됩니다. **초기화하고 시작**을 확인하면 이전 진행이 삭제되므로 신중하게 선택하세요. |

게임 콘텐츠는 내 컴퓨터에서 제공되며, 플레이를 위한 회원가입이나 외부 서비스 로그인은 필요하지 않습니다.

## 실행 확인과 참고 자료

정상 실행되면 시작 화면에 **새 게임**이 보입니다. 게임을 시작해 자료를 열고, 메모를 적은 뒤 새로고침하여 **이어하기**로 복원되는지 확인할 수 있습니다.

자동 검사 방법과 결과는 [개발·검증 기록](docs/development.md)에 정리했습니다. 다음은 코드를 수정하거나 실행 상태를 자세히 확인할 때 사용하는 선택 사항입니다. 일반 플레이에는 필요하지 않습니다.

<summary>자동 검사와 빌드 명령 보기</summary>

브라우저 자동 검사를 처음 실행할 때는 다음 준비가 필요합니다.

```powershell
npx.cmd playwright install chromium
```

게임 폴더에서 다음 명령을 각각 실행합니다.

```powershell
npm.cmd run typecheck
npm.cmd run check:content
npm.cmd run test:unit
npm.cmd run test:e2e
npm.cmd run build
npm.cmd run preview -- --host 127.0.0.1
```

빌드한 게임의 기본 확인 주소는 `http://127.0.0.1:4173`입니다. 평소 실행 주소와 다르므로 저장도 별도로 관리됩니다.
