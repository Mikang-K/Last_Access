# 마지막 접속 공략 — 스포일러

이 문서에는 비밀번호·장소·진상이 모두 포함됩니다.

## 정규 경로

1. 처음 열리는 `먼저 읽어줘.txt`를 읽습니다. 메신저 `너와 서윤`, 사진의 `첫_전시_포스터.svg`, 일정의 `첫 전시 개막 기념` 중 하나로 첫 전시 개막일 4월 17일을 확인합니다.
2. 탐색기 → 전시 → `개인_메모.txt`에 **0417**을 입력합니다. 앞의 0이 필요합니다. 전각 `０４１７`과 앞뒤 공백은 허용하지만 `417`, `04/17`은 오답입니다.
3. 개인 메모에서 복구 키 규칙을 읽습니다. 일정 `TEAL 정산 검토`에서 코드 **TEAL**, 회의실 **04**를 확인합니다. `프로젝트_개요.txt`와 `운영_안내.txt`를 대조해도 됩니다.
4. 전시 → 백업에 **TEAL04**를 입력하고 `백업 폴더 열기`를 누릅니다. ` teal04 `는 허용하고 내부 공백·하이픈은 허용하지 않습니다.
5. 아래 일곱 자료에서 **증거 기록**을 누릅니다. 열람만으로 증거가 자동 수집되지는 않습니다.

| 증거 | 자료 | 확인 내용 |
| --- | --- | --- |
| E01 | 메신저 `민지와 서윤` (C02) | 20:30 별관 옛 포스터가 있던 방에서 만남 |
| E02 | `별관_안내도.svg` (F06) | 옛 포스터는 별관 지하 1층 자료실에 보관 |
| E03 | `변경_기록.txt` (F10) | 18:40 운영실 PC-02, designer 계정으로 설치비 변경 |
| E04 | `민지_확인서.txt` (F11) | 18:40~18:43 키보드를 사용한 실제 작업자는 한도현 |
| E05 | `정산_원본.csv` (F08) | 17:50 승인 원본 설치비 800,000원 |
| E06 | `정산_제출본.csv` (F09) | 18:45 제출본 설치비 1,800,000원 |
| E07 | `정산_제출_안내.txt` (F07) | 공용 계정명만으로 실제 작업자를 판단할 수 없음 |

## 제출

진상 제출 앱에서 아래 답과 **정확한 증거 집합**을 선택합니다. 증거 선택 순서는 상관없습니다.

| 질문 | 답 | 근거 |
| --- | --- | --- |
| Q01 장소 | 별관 지하 1층 자료실 | E01 + E02 |
| Q02 실제 수정자 | 한도현 | E03 + E04 |
| Q03 변경 내용 | 설치비를 80만 원에서 180만 원으로 바꾸고 서윤의 작업처럼 보이게 했다 | E05 + E06 + E07 |

오답이어도 진행·메모·초안은 유지됩니다. 선택을 바꾸고 다시 제출하세요.

## 대체 경로와 마지막 기록

P01을 풀지 않아도 일정 CAL02 또는 F04·F05로 복구 키를 추론해 P02부터 풀 수 있습니다. 모든 자료 열람이나 힌트 사용 여부는 정답 조건이 아닙니다.

`예약_메시지_기록.txt`(F13/E08)는 19:20 등록, 20:30 발송된 예약 메시지임을 보여 줍니다. `오프라인_메모.txt`(F14/E09)는 서윤이 19:25 휴대전화를 끄고 민지와 원본을 대조하러 이동했음을 설명합니다. 두 증거를 수집하지 않아도 엔딩에 도달할 수 있습니다. 20:30 발송은 집 컴퓨터의 실시간 사용 증거가 아닙니다.

18:55 출력소 수령증은 18:40의 알리바이가 아닙니다. 실제 작업자 판단은 변경 기록과 같은 시각의 민지 목격 기록을 대조합니다. 엔딩 후 **계속 조사**로 자료를 더 읽고 메모를 수정할 수 있으며 정답 제출 결과는 보존됩니다.
